# Crop Disease Detection System

An end-to-end disease detection system for agricultural applications, processing drone imagery to detect, classify, and map crop diseases with severity assessment and treatment recommendations.

## Features

- **End-to-End Pipeline**: From drone image input to disease severity maps and alerts
- **Morphological Operations**: Erosion, dilation, opening, closing for lesion refinement
- **Disease Classification**: Identifies leaf spot, blight, and powdery mildew
- **Severity Mapping**: Color-coded severity overlays with percentage calculations
- **Alert System**: Threshold-based notifications for different severity levels
- **Web Dashboard**: User-friendly interface for image upload and result visualization
