1. End-to-End Disease Detection System Design

Integrated pipeline from drone-view input to actionable agricultural alerts.

System Architecture Diagram

graph TD
    Input[Drone Image Input] --> Prep[Preprocessing: Resize & Blur]
    Prep --> Seg[Segmentation: Inverse Green Masking]
    
    subgraph "Morphology & Refinement (Assignment 2 & 3)"
    Seg --> Morph[Morphological Ops: Close/Open/Fill]
    Morph --> Label[Connected Component Labeling]
    Label --> Bound[Boundary & Feature Extraction]
    end
    
    subgraph "Classification & Severity (Assignment 4)"
    Bound --> Class[Decision Rule Classification]
    Class --> Sever[Severity Index Calculation]
    end
    
    Sever --> Map[Overlay Severity Map]
    Map --> UI[Dashboard Visualization]
    Sever --> Alert[Generate Actionable Alerts]
System Inputs
  • • Image: High-res drone/camera photography
  • • Location: Field GPS/Section coordinates
  • • Crop: Lemon (Citrus limon)
  • • Stage: Vegetative / Fruit-bearing
System Outputs
  • • Map: Red-contoured severity overlay
  • • Severity: % Area (0% - 100%)
  • • Alert: Binary flag (Normal/Critical)
  • • Action: Specific fungicide recommendations
Thresholds
  • • Lesion Min: 10 pixels
  • • Green Hue: 35 - 90 (HSV)
  • • Crit Severity: >30% Area
  • • Confidence: >60% score for class

Analysis Insights:

    Optimal Structuring Element Documentation

    Small Lesions (Black Spot)

    Shape: Circular (Ellipse) | Size: 3x3
    Provides high edge precision for tiny, rounded necrotic spots without over-eroding.

    Irregular Fragments (Canker/Anthracnose)

    Shape: Square | Size: 5x5
    Better for connecting jagged lesion borders into a single cohesive region.

    Debris/Noise Removal (Mildew)

    Shape: Cross | Size: 3x3
    Efficient at removing 1-pixel wide artifacts like hairs or soil debris streaks.
